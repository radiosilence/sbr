a proxy core in rust that runs sing-box configs

sbr reads the same configuration files as sing-box and runs them on a core written in Rust. Its app for iPhone, iPad, Mac and Apple TV runs that core inside the system's network extension.

why

  • faster

    On most encrypted paths measured, sbr moves more data per second than sing-box with the same config file and spends less CPU per byte: trojan over TLS is 14–23% faster on Linux, and WireGuard on Apple silicon uploads at about a third of sing-box's CPU per GB. The benchmarks include the paths where sbr is slower.

  • lighter

    iOS stops a packet tunnel extension that uses more than about 50 MB of memory, and Go's garbage-collected heap is why sing-box needs constant tuning to stay under it. sbr has no garbage collector, and a relayed connection costs about 32 KB by default inside the extension.

  • harder to block

    Every TLS connection over TCP sends a ClientHello captured from Chrome, Safari or Firefox. A handshake that is reset or goes unanswered is retried with its ClientHello fragmented, and failover notices servers that complete a handshake and then stop carrying data. See features and censorship.

  • private

    sbr connects only to what your profile names: where sing-box falls back to a third-party default, such as measuring latency against gstatic.com or downloading a dashboard from GitHub, sbr does neither. The app keeps profiles and their credentials in the Keychain, and has no account, no server of its own and no analytics; see the privacy policy.

  • compatible

    Profiles written for sing-box run unchanged, including remote profiles and rule-sets. A field sbr has not implemented is rejected at import with its JSON path, so a profile never routes differently without saying so.

get it

  • iphone, ipad and apple tv

    In beta on TestFlight, where one invitation covers both iOS and tvOS. iOS 26 or tvOS 17 or later. An App Store release is planned.

  • mac

    A notarised app, from Homebrew or as a disk image from the latest release. macOS 26 or later. On first connect, allow its network extension under System Settings › General › Login Items & Extensions.

    brew install --cask radiosilence/tap/sbr
  • command line

    The sbr binary takes sing-box's flags, on macOS and Linux. It is built from source with Rust's toolchain.

    git clone https://github.com/radiosilence/sbr
cd sbr
cargo build --release -p sbr
target/release/sbr check -c config.json
target/release/sbr run -c config.json

Source, issues and documentation are on GitHub.
